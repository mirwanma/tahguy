# TAHGUY — Misi Guyur ARSA

Game perjalanan pelanggan (customer journey) TAHGUY bersama **ARSA, Si Penjelajah Rasa**.
Satu file HTML statis (`index.html`), semua aset sudah tertanam. Tidak perlu build.

## Enam babak
| Babak | Tahap | Mini-game |
|---|---|---|
| 1 | Lihat | Tap video TAHGUY di feed yang makin cepat |
| 2 | Datang | Runner dari Gerbang Unjani ke gerobak di Jl. Terusan Jend. Sudirman |
| 3 | Pesan | Racik menu, level pedas, topping sebelum antrean memanjang |
| 4 | Guyur | Tahan-lepas untuk menuang kuah tepat di zona PAS |
| 5 | Pamer | Jepret saat mangkuk di tengah bingkai dan uap tebal |
| 6 | Balik | Kalender 30 hari + kartu stempel (north star: beli lagi dalam 30 hari) |

Di akhir: rapor, kartu #TahguyMoment, dan tabel "Catatan untuk tim" yang memetakan tiap babak ke touchpoint dan metrik nyata.

## Catatan
- Harga dan mekanik hadiah kartu stempel sengaja belum ditampilkan (belum final).
- Lokasi & jam buka mengikuti brand system TAHGUY (dekat Kampus Unjani, Cimahi · 14.00–22.00).

## Menjalankan
Buka `index.html` di browser, atau aktifkan GitHub Pages (Settings → Pages → branch `main`, folder `/root`).
